
# 👋 Hi, I'm Tamim Hosen

### 🛡️ Cybersecurity Analyst 

## 💫 About Me

I am a **Cybersecurity Analyst** specializing in **Security Operations, Threat Detection, Incident Response, Security Monitoring, Threat Intelligence, and Vulnerability Assessment & Penetration Testing (VAPT)**.

I investigate security incidents, analyze attack vectors and techniques, perform root cause analysis, identify vulnerabilities, and provide actionable security intelligence to help reduce risk and strengthen organizational security posture.

My approach combines **offensive and defensive security**, using an attacker mindset to improve defensive capabilities. I am particularly interested in **Threat Hunting, Red Teaming, Ethical Hacking, VAPT, Detection Engineering, Incident Response, and Purple Team operations**.
